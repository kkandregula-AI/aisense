The core question

Humans read text, look at images, listen to sound and watch video. How can one AI system learn relationships across such different forms of information?

Each data type starts in its own form. The system turns each one into machine-readable representations, then aligns or integrates them so it can learn that a sentence, a photo and a sound can all describe the same thing.
